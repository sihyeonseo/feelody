# 한국어 추천 평가 · 동일 후보 비교

## 포트폴리오 3페이지 교체 문안

**일기에 어울리는 곡을 찾고도, 왜 최종 추천에서 놓쳤을까?**

중복을 합친 가사 2,242개에서 E5-large로 30개를 검색하고, 같은 후보를 세 가지 방식으로 정렬했다. 일기 10편에서 감정 적합도를 0~3점으로 채점하고 2점 이상을 적합으로 집계했다.

| 같은 후보를 정렬한 방법 | 적합한 추천 / 30자리 | 적합곡을 받은 일기 / 10편 | MRR@3 |
|---|---:|---:|---:|
| E5 검색 순서 | 4 | 3 | 0.250 |
| KURE-nano | 10 | 6 | 0.433 |
| BGE-reranker-v2-m3 | 7 | 7 | 0.350 |

**실패 추적**　KURE가 적합곡을 하나도 주지 못한 4편 중 3편은 이미 후보 안에 적합곡이 있었다. 039번에서는 E5 검색 19위의 3점 곡을 KURE가 놓쳤고, 같은 30곡을 BM25로 정렬하자 그 곡이 1위로 올라왔다. 나머지 실패 1편은 후보 8/30개만 채점되어 원인 판단을 보류했다.

## 무엇을 결정할 수 있는가

- 3곡 전체의 적합률과 한 곡이라도 맞는 일기의 비율은 모델 순서가 달라진다. 제품 목표에 따라 주지표를 미리 정한다. 같은 10편을 반복 분석한 탐색 결과다.
- 공개용 pilot_summary.json의 pooled_ndcg는 각 일기에서 채점된 후보만으로 이상 순서를 근사한다. 양의 등급이 없는 045를 제외한 9편 평균이다. 전체 후보를 채점한 NDCG와 구별한다. 전체 카탈로그의 감정 적합곡 수는 알 수 없어 진짜 Recall@30은 산출하지 않았다.
- 114편 기존 개발셋의 지정 참고곡 상위 30개 포함 건수는 문자 bigram BM25 44편, 기존 E5-small 직접 검색 14편, E5-small 감정 앵커 8편이었다. 보류한 28편은 평가하지 않았다. 지정곡 하나의 순위와 감정 적합도는 서로 다른 평가다. 이 비교에는 E5-large의 114편 결과가 들어 있지 않다. 참고곡을 바탕으로 쓰거나 곡명·가사 표현이 겹치는 일기가 있는지는 별도 감사가 필요하다.
- 같은 BM25를 10편의 고정 후보에 적용한 결과 상위 30자리 중 적합 3개, 부적합 9개, 미채점 18개였다. Precision@3의 가능한 범위는 10~70%다. 039번 회복만으로 기본 모델을 교체하지 않는다.
- Linux CPU 8스레드, float32, 1회 워밍업 뒤 저장된 10회 측정에서 중앙값은 검색(일기 인코딩 포함) 0.49초, KURE 16.76초, 전체 17.09초였다. 총시간 합계 중 재순위화는 97.36%였다. 글로벌 웹 API의 응답시간과 별개다. 엔지니어링 후속 실험은 동일 후보·동일 하드웨어에서 배치 크기에 따른 지연과 순위 일치를 함께 측정한다.

## 재실행

기준 저장소 커밋은 8ed43d651c9a2f4f3d53f9fa38d49f1c69a3064e다. private는 예전 실험 파일을 모은 로컬 폴더다. 모델을 다시 호출하지 않고 저장된 순위와 사람 채점 키를 결합한다. 실험 코드가 요구하는 파일명은 각 스크립트에서 확인할 수 있다.

    python evaluation/pilot_audit.py private out

BM25는 단어 경계 안에서 한글·영문·숫자의 문자 bigram을 만들고 한 글자 단어는 유지한다. k1=1.2, b=0.75, 질의 내 중복 토큰은 한 번만 센다. 재순위화에도 전체 카탈로그 문서빈도를 사용한다. 기본값으로 한 번 실행했다.

## 감정 점수 결합 실험

첨부한 Colab 노트북과 개인 연구용 입력 ZIP을 사용한다. E5의 검색 순위는 고정하고 같은 30곡에 KURE와 14개 감정 앵커를 적용한다. 앵커는 기존 B3의 문구를 재사용하고 인코더는 E5-large로 통일한다. 일기와 가사를 passage, 앵커를 query로 인코딩한다. 후보 30개 안에서 각 신호를 순위 백분위로 바꾼다. E5+KURE와 E5+KURE+감정의 동일 가중치 비교를 사전에 고정했다. 실험군의 기존 두 신호 간 상대 가중치는 1:1로 유지된다. 감정 점수는 분류 확률이 아니다.

노트북은 원본 KURE의 최종 순서와 재실행 결과의 일치 편수를 표시한다. 불일치가 있으면 런타임·모델·정밀도 차이를 확인한 후 결론을 낸다. GPU 추론은 이번 작업에서 실행하지 않았다. 결과에 미채점 곡이 섞이면 0점 대체 없이 가능한 지표 범위를 반환한다. 10편은 탐색용이고 감정 신호 채택은 새 일기 블라인드 평가에서 결정한다. 서로 독립적인 평가자 2인이 점수와 불일치 사유를 기록한다.
